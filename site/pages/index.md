# Development code archaeology

<figure markdown="1">
![From originator code, through name changes, mergers and licensing, to the INN](images/from-code-to-inn.png)
<figcaption>From the first article, <a href="https://www.linkedin.com/pulse/data-archaeology-tracing-drug-development-codes-through-forsberg-89t1e/">Data Archaeology</a>, December 2025.</figcaption>
</figure>

Before a drug has an INN (International Nonproprietary Name, the generic name WHO assigns), it has a
development code: AZD0914, BI 1015550, MK-3475, which became pembrolizumab. Often it has more than one, because
licensing deals, mergers and renamed companies each leave a new code behind. The trials from those years stay
in the registry under the code they were registered with. A search on the INN finds only the top layer.

This site follows the digging: collecting codes from named sources, checking each find against the record,
counting the trials it brings back, and publishing it to Wikidata with references, so the next person does
not have to dig again.

The field notes are numbered and keep their figures once written. The reference pages are updated as the work goes on.
