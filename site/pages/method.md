# Method

Code harvest, review and trial search. The notebooks are generated by builder scripts in the repository;
every source, rule and decision is in a file. Full description:
[`trial_archaeology/documents/development_code_archaeology_process.md`](repo:trial_archaeology/documents/development_code_archaeology_process.md).

## Sources

| Source | Gives | Known weakness |
|--------|-------|----------------|
| NCI Thesaurus (EVS API) | Curated synonyms, code type (term type CN) | Merges biosimilar codes into the originator concept; typos (PR070769 for PRO70769) |
| PubChem synonyms | Depositor synonyms for small molecules and peptides | Vendor numbers, depositor typos (GSK685968 next to GSK685698) |
| AACT other names | What sponsors registered | Codes of combination partners; some records repeat NCIt synonym lists |
| AACT intervention names | Codes extended with a suffix (ONO-4538HSC) | Other formulations and products |
| Web, LLM-assisted | Originator, partner and combination codes from press releases, protocols, regulators | Every code must cite the URL where it was seen |

## Evidence rule

A candidate (INN × code) is accepted when it has two or more independent lines of evidence: a source, a
distinct web publisher, or registry trials. The rule can be checked without domain expertise. Candidates
found only in PubChem, with no trials, are set aside as unconfirmed.

## Review

Each candidate gets a class. AI-proposed classes are marked `claude-proposed` until a person confirms them;
rows where the review and the rule disagree go to an exception list. Open questions end in hold.

| Class | Meaning | Searched |
|-------|---------|----------|
| current | Sponsor code at approval | yes |
| legacy | Earlier code: originator, licensor, predecessor | yes |
| partner | Co-development or regional partner | yes |
| other_product | Combination, co-formulation, other formulation | no |
| biosimilar | Another company's copy | no |
| other_drug | Code of a different drug in the same record | no |
| typo | Misspelled code | no |
| not_a_code | Vendor, ATC, NSC, approval number, clone name | no |

## Matching rule

One rule for harvest and search ([`patterns/aact_matching.py`](repo:patterns/aact_matching.py)): a code is a
token, with no letter or digit directly before or after, in all spellings (as given, without separator, space
and hyphen swapped). MK-3475 finds MK-3475-001 but not MK-3475A. Sponsor study codes that embed the
development code (Novartis CLOU064A2402) are matched by ruled patterns. The INN is matched in the
intervention name.
