Method

Code harvest, review and trial search. The notebooks are generated by builder scripts in the repository; every source, rule and decision is in a file. Full description: trial_archaeology/documents/development_code_archaeology_process.md.

GSRS, ChEMBL and MeSH were added on 2026-11-21, after the Hässle codes showed what was missing (field note 4). Each is reached from the substance's UNII and followed to its salt records, because a code often sits only on the salt (H 168/68 SODIUM; GSK573719A on umeclidinium bromide). For the Hässle lists, PubMed records and AB Hässle's US patents are used as well; patents never decide a code's status.

Evidence rule

A candidate (INN × code) is accepted when it has two or more independent lines of evidence: a source, a distinct web publisher, or registry trials. The rule can be checked without domain expertise. Candidates found only in PubChem, with no trials, are set aside as unconfirmed.

GSRS, ChEMBL and PubChem draw on each other, so together they count as one line of evidence. By rule (2026-11-21): NSC numbers and ChEMBL trade names are not_a_code; CAS numbers and PubChem vendor IDs are set aside; only active MeSH records are used.

Review

Each candidate gets a class. AI-proposed classes are marked claude-proposed until a person confirms them; rows where the review and the rule disagree go to an exception list. Open questions end in hold. A reviewer can also exclude a single trial for one code, for example when the drug is only a probe in another sponsor's trial (collections/<collection>_trial_exclusions.csv).

Matching rule

One rule for harvest and search (patterns/aact_matching.py): a code is a token, with no letter or digit directly before or after, in all spellings (as given, without separator, space and hyphen swapped). MK-3475 finds MK-3475-001 but not MK-3475A. Sponsor study codes that embed the development code (Novartis CLOU064A2402) are matched by ruled patterns. The INN is matched in the intervention name.

A separator inside the number is part of the code and is never removed (H 234/09, BMS-562247-01, NNC 0113-0217). Without it, H 234/09 becomes H-23409, and in ClinicalTrials.gov that is a Baylor IRB number (NCT00831480), not almokalant.
