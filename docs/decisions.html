Publication decisions

The approach is conservative: nothing is published that depends on an assumption. Each open question ends in hold, with the reason recorded. A held code stays an alias and remains usable for search.

Rules

  • Which codes. Only codes confirmed by a person in review, accepted by the evidence rule and used in search.
  • Which item. The item of the level the code names: active moiety, salt (only where the evidence names the salt) or fixed combination. Items are found by UNII.
  • Which reference. A ClinicalTrials.gov record (NCT ID) with the assigning company as lead sponsor; otherwise NCI Thesaurus if it is a source; otherwise not published. PubChem and Wikipedia are not used as references.
  • Which company. Qualifier P1027 "conferred by", the company that assigned the code.
