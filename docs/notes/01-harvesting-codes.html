Field note 1 · covers October – November 2026

Harvesting development codes from named sources

The first field note ended with two questions. This note is about the first: can development codes be harvested programmatically, from named sources?

In December I asked an AI to find the codes, and then checked them by hand. That worked, but it does not scale, and the AI produced codes that no source had. So in October I turned it around: collect candidate codes from sources that can be named and queried, and let the AI help write the code and look for web sources, not remember the answer.

A rule I can check, and a person who decides

I am not a domain expert for judging individual development codes. So the first filter is a rule anyone can check: a code is accepted when two independent lines of evidence agree, a source, a distinct web publisher, or trials in the registry. Codes found only in PubChem, with no trials, are set aside.

Then each candidate gets a class in review: current code, legacy code, partner code, or one of the classes that are not searched: another product, another drug, a biosimilar, a typo, not a code. The AI proposes a class; it is marked as proposed until I confirm it. Where the rule and the review disagree, the row goes to an exception list. Where a question stays open, the code is held, and the reason is written down.

What I learned

  • AI can find codes; only sources can prove them. Now every code has a named source, and a code found on the web cites the URL.
  • No source is complete. Some current codes exist only in the registry (tirzepatide LY3298176). Some only on the web and in trial records (elinzanetant GSK1144814).
  • Sources copy each other. Some trial records, NCI-sponsored and academic, appear to carry NCI Thesaurus synonym lists as other names. For those codes the registry is not an independent witness.
  • Sources have typos. NCI Thesaurus lists PR070769 next to PRO70769, the letter O read as a zero. The same typo is on Wikidata as an alias.
  • A trial record lists more than the drug. Combination partners, co-formulations and other products sit in the same "other names" field. Without review they would inflate the count of hidden trials.
